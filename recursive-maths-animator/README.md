# Recursive Maths Animator skill

This directory is the installable skill. Read [`SKILL.md`](SKILL.md) for the
canonical workflow and [`QUICK_START.md`](QUICK_START.md) for commands.

It provides Manim rendering, optional voiceover, physics scenes, responsive
layout guidance, frame verification, and final MP4 delivery.

Useful paths:

- `examples/` — runnable animation and physics scenes.
- `requirements.txt` — project dependencies.
- `scripts/` — environment checks and frame extraction.
- `references/video_verification_rubric.md` — review checklist.

For installation and examples, see the repository [README](../README.md).
